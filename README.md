## Cara Menggunakan Repository

### 1. Clone Repository

Clone repository ke komputer masing-masing:

```bash
git clone https://github.com/rrrambatsigma/praktikum2026-smbd.git
```

Kemudian masuk ke folder repository:

```bash
cd praktikum2026-smbd
```

### 2. Pilih Folder Pertemuan

Masuk ke folder sesuai dengan pertemuan yang sedang dikerjakan.

Contoh:

```text
pertemuan-01/
```

### 3. Baca Dokumentasi

Sebelum menjalankan praktikum, baca dokumentasi pada Google Docs untuk mengetahui:

* tujuan praktikum,
* tools yang digunakan,
* langkah-langkah praktikum,
* konfigurasi yang diperlukan,
* dan tugas yang harus dikerjakan.

## Tools

Tools yang digunakan dapat berbeda pada setiap pertemuan. Untuk Pertemuan 1, tools utama yang digunakan adalah:

* **Microsoft SQL Server**
* **SQL Server Management Studio (SSMS)**

Pastikan SQL Server dan SSMS telah terpasang dan dapat digunakan sebelum mengikuti praktikum.

---

## Catatan

* Ikuti langkah praktikum sesuai dokumentasi yang diberikan.
* Perhatikan konfigurasi SQL Server sebelum melakukan perubahan.
* Simpan file backup/database pada lokasi yang mudah ditemukan.
* Jangan menghapus atau menimpa database yang digunakan untuk praktikum tanpa memastikan bahwa backup sudah tersedia.
* Jika mengalami error, baca pesan error terlebih dahulu dan lakukan troubleshooting berdasarkan dokumentasi.
